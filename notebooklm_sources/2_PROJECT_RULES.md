# 💡 專案實務設計哲學與未來改進方向總覽

本文件為 NotebookLM 專用討論大腦。摒棄學術理論與教條式文字，著重於各專案的**實務痛點**、**設計想法**與**未來實務改進方向**。

---

## 1. 📡 手機門號定位 (Cell-Tower-Map-Locator)
- **實務痛點**：警務與調閱人員取得電信業者回傳的基地台基站資料時，原始格式多為複雜文字或表格，手動對照座標耗時且容易看錯位置。
- **設計想法**：
  - 堅持 100% 純前端離線運算，保護敏感個資與定位隱私。
  - 使用 Leaflet 地圖，自動提取座標與門號，即時在地圖上畫出基地台扇形覆蓋區 (L.polygon) 與涵蓋範圍。
  - 加入台灣邊界座標自動校驗 (Lat 21-27, Lng 118-124) 與 XSS 防護。
- **未來改进與討論方向**：
  - 引進 3D 建築物地形模型，模擬都市叢林中基地台訊號的反射與遮蔽。
  - 增加多門號軌跡時間軸重疊比對，自動標記出「同時間同基地台」的潛在交會點。

## 2. 🖼️ 警務影像格式轉換工具 (Police-Image-Toolkit)
- **實務痛點**：員警使用 iPhone 拍攝的 HEIC 照片或長截圖，上傳至警務公務系統時常因格式不符或檔案過大而被退件。
- **設計想法**：
  - 100% 瀏覽器本機端轉檔與壓縮，絕不上傳第三方伺服器。
  - 獨家「長截圖自動切片算法」：以公分 (CM) 計算重疊區域，避免裁切時切斷文字。
  - 內建 3x3 卷積核銳化濾鏡，提昇車牌與證件文字清晰度。
- **未來改進與討論方向**：
  - 引進 Web Workers 多執行緒運算，避免大批量轉檔或高解析度圖片造成 UI 畫面凍結。
  - 加入輕量化本機 OCR 辨識，自動把圖片中的車牌或身分證號轉成文字檔存檔。

---

## 3. 📈 金融資料轉檔工具 (Financial-Data-Parser)
- **實務痛點**：匯入金融機構 CSV 或文字檔時，常因為前導零缺失 (例如帳號 00123 變成 123)、中文亂碼或金額符號雜亂而造成資料處理錯誤。
- **設計想法**：
  - 採用 SheetJS 進行數據處理，強制指定帳號欄位為字串型態 (`t: 's'`)，防止 Excel 自動吃掉前導零。
  - 智慧 Regex 正規化引擎：自動過濾 `$`, `,`, `+` 等非數字字元。
  - 支援單頁堆疊、分頁合併與 Zip 壓縮包遞迴解壓。
- **未來改進與討論方向**：
  - 加入金流異常交易自動預警規則（例如：短時間內頻繁整數大額轉帳自動標記紅字）。
  - 支援可自訂的對帳欄位對應拖曳介面。

## 4. 📷 現況照片清冊生成工具 (Photo-Report-Generator)
- **實務痛點**：現場蒐證照片動輒數百張，手動貼到 Word 排版並填寫照片說明極度耗時。
- **設計想法**：
  - 打造輕量 Web Landing Page 結合 Excel VBA 巨集工具。
  - 一鍵匯入照片資料夾，自動在 Word/Excel 中依照公務標準格式產出兩排或四排的相片清冊。
- **未來改進與討論方向**：
  - 把 VBA 邏輯完全 Web 網頁化，直接在瀏覽器線上拖曳圖片並輸出帶有浮水印與格式的 PDF 報表。

## 5. 📅 排班表與卡片小卡 (Calendar-Card-App)
- **實務痛點**：單位內部排班表多為複雜的 Excel 大表格，同仁手機查班極不方便。
- **設計想法**：
  - 結合 Google Sheets API，將排班資料轉換為視覺化的個人每日排班卡片。
  - 設定檔採用 Token 安全驗證與配額限制，防範 API 流量被濫用。
- **未來改進與討論方向**：
  - 支援一鍵匯出 `.ics` 檔案，讓同仁直接把班表同步到手機系統行事曆。

---

## 6. 🖼️ 智慧照片整理工具 (Smart-Photo-Organizer)
- **實務痛點**：硬碟與 OneDrive 裡累積數萬張現場照片與截圖，檔名混亂且有大量重複備份。
- **設計想法**：
  - 利用 Python 讀取 EXIF 中繼資料，自動依「年月/日期/地點」建立資料夾分類。
  - 內建雜湊比對機制，自動識別與過濾重複相片。
- **未來改進與討論方向**：
  - 整合本地輕量 AI 相冊標籤（如依據「車牌、證物、人物、文件」自動標籤與分類）。
  - 為 Python 補上 EEL 或 Vue 現代化網頁 UI 介面，方便即時預覽分類結果。

## 7. 🛠️ 檔案整理大師 (System-Optimizer-Tool)
- **實務痛點**：系統暫存檔、重複備份檔佔用寶貴硬碟空間，舊式批次檔介面不友善。
- **設計想法**：
  - 提供即時操作的直覺式介面，支援自然排序與批量重命名。
  - 內建安全機制，禁止父目錄誤移入子目錄等危險操作。
- **未來改進與討論方向**：
  - 打包為 Tauri 輕量桌面程式，結合視覺化硬碟空間圓餅圖。

## 8. 📹 AG-MONITOR 科技偵查雙軌工作站 (AG-Monitor-Forensics)
- **實務痛點**：監視器裸流 (.dav, .h265, .264) 格式特殊，傳統軟體無法播放或轉檔極慢；人工盯看畫面極易疲勞漏看。
- **設計想法**：
  - PyAV 全記憶體零拷貝極速解碼，解決壞軌容錯問題。
  - 整合 Ultralytics YOLOv8 + ByteTrack：即時辨識人、車、機車、公車等目標。
  - 採用 Eel 框架搭配 HTML5 Canvas 前端渲染與 WebSocket 雙向通訊。
  - 獨家「智慧空景快轉」與「抗抖動過濾演算法」，減少無關截圖與誤報。
- **未來改進與討論方向**：
  - 引進車牌區域自動超解析 (ESPCN) 增強引擎，自動提升模糊車牌解析度。
  - 支援雙鏡頭或多路監視器串流同時進場辨識。

## 10. 🤖 行政效能領航員 (auto-learning-bot)
- **實務痛點**：公務數位研習平台 (臺北E大, eCPA, 我的E政府) 流程繁瑣，需重複登入與作答。
- **設計想法**：
  - 使用 Python + Selenium/Playwright 實現自動化課程播放、問卷填寫與測驗答題。
  - 建立本地 SQLite 題庫與 AI 自動補答機制。
- **未來改進與討論方向**：
  - 優化 Session 過期自動重登與異常自動修復機制。
