# 🚀 辦公室 Antigravity 一鍵同步、NotebookLM 脫水與憲法融合工具包

> **帶到辦公室電腦，雙擊 `RUN_OFFICE_SETUP.bat` 即可一鍵完成所有配置！**

---

## 📋 工具包功能總覽

### 1. 雙擊 `RUN_OFFICE_SETUP.bat` 啟動主選單：
- **[1] 一鍵覆寫/升級辦公室憲法**：將今日討論的《全域開發與 Agent 實戰憲法 v3.0》秒級寫入辦公室 Antigravity 系統腦區。
- **[2] 一鍵生成 NotebookLM 脫水封包**：掃描辦公室專案，產出純淨 UTF-8 無亂碼的 `notebooklm_sources/` 4 份 Markdown 檔案，直接可拖入 NotebookLM！
- **[3] 雙源憲法大融合 (v4.0)**：自動比對辦公室舊內規與住家 v3.0，合成最新的 v4.0 大一統憲法。
- **[4] 離場防呆 Commit & Push**：離場前一鍵自動把辦公室今日寫好的功能 Commit 並 Push 至 GitHub，避免雙邊版本衝突！

---

## 💡 辦公室對話直接複製 Prompt (貼給辦公室 Antigravity)

如果不開批次檔，可以直接複製以下 Prompt 貼給辦公室的 Antigravity：

```markdown
請身為 Tech Lead 依據《全域開發與 Agent 實戰憲法 v3.0》，幫我執行以下任務：

1. 掃描當前專案，產出 `notebooklm_sources/` 脫水封包 (100% 繁體中文 UTF-8 無亂碼)。
2. 若本機有辦公室舊內規，請進行「雙源憲法大融合」，將其揉合升級為 v4.0 全域憲法並覆寫至系統腦區。
3. 下班離場前，請自動檢查代碼變更，執行 `git add .`、`git commit -m "WIP: 離場暫存"` 並強制 `git push`！
```
